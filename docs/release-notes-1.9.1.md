---

## Play Console（ユーザー向け・詳細）

### 概要
スマートフォン用アプリの Bluesky/PDS 連携設定を改善し、利用者がご自身の PDS サービス URL を入力して同期する方式に統一しました。ウォッチアプリの機能に変更はありません。

### 新機能 / 修正・改善
- **PDS サービス URL を利用者入力に変更** — これまで初期値として埋め込まれていた特定のサーバー URL を廃止し、利用者がご自身の PDS サービス URL を入力する方式にしました。
- **プライバシーに関する案内の見直し** — プライバシーポリシーの連絡先を、Google Play に表示されるデベロッパー連絡先へご案内する形に変更しました。

## Internal Notes

### バージョン
- app（Wear）: `versionCode` 109010 / `versionName` 1.9.1 → `wear:internal` トラック
- companion（phone）: `versionCode` 109011 / `versionName` 1.9.1 → `internal` トラック
- semver からの自動採番: `(major*10000 + minor*100 + patch)*10 + offset`（app offset=0 / companion offset=1）。1.9.0（Wear 109000 / phone 109001）より単調増加。

### 主な変更
- **PDS デフォルト URL の削除**（PR #50）。`PdsCredentialsStore` に埋め込まれていた個人サーバー（`https://pds.marufeuille.dev`）の既定値を削除し、サービス URL を利用者入力前提の保存に変更。
- **プライバシーポリシーから個人連絡先を除去**（PR #50）。`docs/privacy-policy.html` の個人メールアドレス記載を削除し、Google Play 表示のデベロッパー連絡先へ誘導する文言に修正。
- **ドキュメント更新**（PR #50）。`docs/build.md` の PDS 関連記述と `AGENTS.md` を併せて更新。
- **検証**（PR #50）。`PdsCredentialsStoreTest` を追加し、既定値が埋め込まれないこと・利用者入力の保存挙動を検証。

### Play 提出時の注意
- **データセーフティ申告とプライバシーポリシーの整合を再確認**。PDS への送信は引き続き利用者が URL とハンドル/App Password を設定した場合のみ発生する（デフォルトの送信先は無くなった）。公開中のプライバシーポリシー（個人メール削除済み・デベロッパー連絡先へ誘導）と Play のデータセーフティ申告が本変更と一致していることを確認すること。
- **DB の破壊的変更は本リリースには無い**（companion DB スキーマ変更なし）。
- 既存テスターで PDS 同期を利用していた場合、本バージョン更新後に同期を続けるにはサービス URL の再入力が必要になる可能性がある。
