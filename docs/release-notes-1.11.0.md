# Intervo 1.11.0 Release Notes

## Play Console「最新情報」用（コピペ可・500字以内）

```
インターバルタイマーの休憩まわりを改善しました。
・休憩時間を「無制限（自由）」に設定できるようになりました。自分のペースで休んで、用意ができたら次へ進めます。
・休憩中の残り時間を ±10 秒で微調整できるようになりました（下限 1 秒）。
・カウントダウン・フェーズ切替・ワークアウト完了時にビープ音が鳴るようになりました（端末のアラーム音量に依存します）。
・設定した休憩時間はこれまでどおり使えます。既存のエクササイズ設定は変わりません。
```

---

## Play Console（ユーザー向け・詳細）

### 概要
インターバルタイマーの休憩の使い勝手を拡張しました。「時間を決めずに自分のペースで休む」「残り時間を少し伸ばす・縮める」という操作ができるようになり、あわせてカウントダウンと切替のタイミングでビープ音が鳴るようになりました。

### 新機能 / 修正・改善
- **休憩を「無制限（自由）」に設定可能** — セット間休憩・レップ間休憩を、時間を決めずに「タップするまで待機」できます。無制限に設定すると残り時間は 0 からカウントアップし、用意ができたらスキップ操作で次へ進めます。エクササイズ編集画面の休憩行で「指定／自由」を切り替えられます。
- **休憩中の ±10 秒調整** — セット間休憩・レップ間休憩の残り時間を、休憩中に 10 秒単位で伸ばす・縮められるようになりました（下限 1 秒）。休憩画面の操作が「スキップ」単体から「-10 ／ skip ／ +10」の 3 ボタン構成になります。
- **ビープ音の追加** — カウントダウンの残り 3・2・1 秒、運動↔休憩のフェーズ切替、ワークアウト完了のタイミングでビープ音が鳴ります。既存の振動と並行して発火し、端末のアラーム音量に連動します（音量を下げている場合は小さく鳴ります）。

## Internal Notes

### バージョン
- app（Wear）: `versionCode` 111000 / `versionName` 1.11.0 → `wear:internal` トラック
- companion（phone）: `versionCode` 111001 / `versionName` 1.11.0 → `internal` トラック
- semver からの自動採番: `(major*10000 + minor*100 + patch)*10 + offset`（app offset=0 / companion offset=1）。1.10.0（Wear 110000 / phone 110001）より単調増加。

### 主な変更
- **#70 feat(timer): 休憩を「無制限」に設定可能にする** — `restSeconds` / `repRestSeconds` に sentinel `-1`（`REST_UNLIMITED`）を導入。無制限時は残り秒数を 0 からカウントアップし、進捗リングの分母（`totalSeconds`）には 0 算入して表示が壊れないようにした。DB 列は `INTEGER NOT NULL` で `-1` を保持できるため**スキーマ変更・マイグレーション不要**。エクササイズ編集画面に「指定／自由」の pill トグル（`RestTargetToggle` / `RepRestTargetToggle`）を追加。companion 履歴詳細にも「無制限」表示を追従させ、PDS エクスポート（`WorkoutPdsRecordMapper`）の推定時間算入から `-1` を除外（`takeIf { it >= 0 }`）。
- **#65 feat(timer): 休憩中の±10秒調整とビープ音を追加** — `TimerEngine.adjustRest` で休憩中（`RestPhase` / `RepRestPhase`）の残り秒数を ±10 秒調整可能（下限 1 秒、運動中は無効）。タイマー画面の休憩中操作を「スキップ」単体から「-10 / skip / +10」の 3 ボタン（`RestAdjustButtons`）に変更。`BeepManager` を新設し、カウントダウン（`TONE_PROP_BEEP`, 120ms）・フェーズ完了（`TONE_PROP_ACK`, 250ms）・ワークアウト完了（`TONE_PROP_PROMPT`, 600ms）を `AudioManager.STREAM_ALARM` / `MAX_VOLUME` の `ToneGenerator` で鳴らす（生成失敗時は無音フォールバック）。既存の振動は維持。
- **#62 test(companion) / #63 docs(graph) / #71 chore(skills) / #72 chore(scripts)** — CI 内部・テスト・ドキュメント・開発支援の変更でユーザー影響なし。

### Play 提出時の注意
- 新機能2つは app（Wear）側。companion は履歴詳細の「無制限」表示追従のみで機能差分は小さいが、両 AAB とも versionCode が更新され同一リリースで配信される。
- ビープ音は `STREAM_ALARM` を使用。マナーモードではなくアラーム音量に依存するため、データセーフティ申告に影響する新規の外部送信・権限追加はなし。
- DB スキーマの破壊的変更はなし（sentinel `-1` を既存列で保持）。既存の `restSeconds >= 0` は従来どおり「指定」扱いで、既存ユーザーのエクササイズ設定への影響はない。
- PDS へ送るデータに心拍数は引き続き含めない（推定時間算入の修正のみ）。
