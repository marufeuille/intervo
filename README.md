# Intervo

Pixel Watch 4 向けの筋トレインターバルタイマー Wear OS アプリ。

## 機能

- **ワークアウト管理** — 「上半身」「下半身」など複数のワークアウトを作成・編集
- **エクササイズ編集** — 種目名・運動時間・セット数・休憩時間を手元で設定
- **インターバルタイマー** — 運動→休憩のカウントダウンをバイブレーションで通知（音なし）
- **Ambient Mode 対応** — タイマー中にスリープしても残り時間を常時表示
